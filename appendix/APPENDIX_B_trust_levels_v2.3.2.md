# 부록 B – 외부 데이터 신뢰도 기준표
버전: v2.3.2  
최종 개정일: 2025-08-12  
소유자: LG U+ CHO부문 Innovation CoE팀 (email: hkchoi00@lguplus.co.kr)

## 목적
외부 출처 기반 수치의 신뢰도를 정량화하여 보고서 요약 표에 등급과 근거를 함께 표기합니다.

## B-1. 평가 항목(0–2점, 최대 8점)
1) **출처 유형(Source Type)**: 0 익명/비전문, 1 일반 미디어·3rd party, 2 **공시/정부/저명 리서치/1st party**  
2) **최신성(Recency)**: 0 >180일, 1 91–180일, 2 **≤90일**  
3) **방법 공개(Method Transparency)**: 0 비공개, 1 부분 공개, 2 **표본/수집/산식 명확**  
4) **교차검증(Corroboration)**: 0 단일 출처, 1 동종 2개, 2 **이종 2개 이상 일치**

## B-2. 등급 매핑
- **High**: 7–8점  
- **Medium**: 4–6점  
- **Low**: 0–3점

## B-3. 보고서 표기 예시
`신뢰도: High (7/8) — 출처=공시(2), 최신≤90일(2), 방법공개(2), 교차검증 2건(1)`

## B-4. 추가 원칙
- **스코프 일치**: 지역/플랫폼 상이 시 **가중 평균** 또는 **분리 표기**  
- **추정치(Estimate)**: 도구 추정은 반드시 **Estimate**로 명시  
- **법·윤리 준수**: 서비스 약관·**robots.txt** 준수, 개인정보·기밀 미수집
